# Glossário

| Termo | Significado |
| --- | --- |
| Agilis | Nome de produto do SGC |
| SGC / SGA | Sigla do sistema (SGC no código e nos textos; SGA é o nome da pasta) |
| Ação | Unidade de trabalho com prazo, status, responsável, tempo, tarefas e impedimentos |
| Diretriz | Direcionamento do Diretor, que vira uma ação em cada seção destinatária |
| Tarefa | Item de apoio dentro de uma ação (`acao_checklist` no banco). Não muda o status |
| Impedimento | Algo que trava uma ação; `critico` deixa a seção vermelha. Histórico, nunca editado |
| Seção | Qualquer unidade da árvore: Centro, Coordenação, Subseção ou Diretoria Adjunta |
| Unidade de acompanhamento | Seção que vira cartão na reunião e linha do Painel: Centro, Coordenação, Diretoria Adjunta |
| Subseção | Seção abaixo de outra; nunca é cartão e soma no cartão acima |
| Diretoria Adjunta | Seção de primeiro nível, sem chefe, que substitui o Diretor nas ausências; membros têm perfil Administrador |
| Ação interna | Ação de subseção marcada `interna`; invisível ao Diretor e ao Apoio |
| Semáforo | Cor (vermelho/amarelo/verde) com forma e texto que resume a situação da unidade |
| Atualização semanal | Relato do chefe, versionado, congelado ao enviar |
| Fechamento | Segunda-feira, 18h |
| `refTerca` / referência da reunião | Data da reunião à qual as atualizações de hoje se referem |
| Pedido de prazo | Solicitação de novo prazo para ação criada por outra pessoa |
| Combinado | Regra de convivência lembrada na abertura da reunião; arquivado, nunca excluído |
| Decisão | Registro feito durante a reunião |
| Ata | Texto gerado ao encerrar a reunião; rascunho → enviada |
| Modo Reunião | Tela para TV com letras grandes, navegada por setas |
| Suplente | Segundo chefe da mesma seção, com os mesmos poderes do titular |
| Membro da equipe | Perfil que age só no que é dele |
| Consulta | Perfil de leitura das ações de todos os Centros |
| Plataforma | Perfil que administra empresas |
| Empresa | Órgão atendido; a Empresa 1 é o original |
| Vocabulário | Nomes dos tipos de unidade e do topo, próprios de cada empresa |
| Topo | Perfil mais alto da empresa (por padrão, "Diretor") |
| Ciência / vista | Registro de que a pessoa abriu a ação recebida |
| Ação parada | Em curso e sem movimentação há 7 dias ou mais |
| Esforço | Estimativa (pequeno, médio, grande) usada na produtividade |
| RLS | Row Level Security do PostgreSQL, habilitada pela migração 4 |
